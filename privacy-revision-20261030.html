개정안: 아래 AI 처리 설명은 2026-10-30 운영 상태를 대조한 개정안이며, 시행 예정일은 2026-11-29입니다. 시행 전까지 현재 방침을 대체하지 않습니다. 현재 시행 중인 방침은 기존 개인정보처리방침에서, 변경 내용은 개정 안내에서 확인하실 수 있습니다.

1. 수집하는 개인정보 항목

서비스는 아래 정보를 수집·저장합니다.

  • 로그인 식별자: 이메일 등 계정 식별정보(Google·Kakao·Apple·이메일 로그인)
  • 이용자가 입력한 독서 기록: 책·별점·한줄평·메모·독서 상태 등
  • 이용자가 업로드한 이미지: 독서 기록 사진, 메모 사진. 프로필 사진은 현재 기기에만 저장됩니다.
  • 서비스 이용 기록: 앱 내 주요 동작 이벤트(자체 통계 및 서비스 개선 목적으로만 사용하며, 광고 식별자나 제3자 분석 도구를 사용하지 않습니다)

2. 접근 권한

서비스는 아래 단말 권한을 기능 제공에 필요한 범위에서만 사용합니다.

  • 카메라: 독서 기록·메모 사진을 촬영해 첨부하기 위해 사용합니다.
  • 사진 저장: 결산 카드와 기록 이미지를 사진첩에 저장하기 위해 사용합니다. 저장 전용이며, 사진첩을 읽는 권한은 사용하지 않습니다.
  • 사진 첨부: 프로필·기록 사진을 첨부할 때는 단말의 사진 선택기를 통해 이용자가 직접 고른 사진만 전달받습니다.
  • 마이크: 사용하지 않습니다.

3. 이용 목적

수집한 정보는 서비스 제공(기록·결산·백업), 통계 생성, 서비스 내 책 추천 개선 목적으로 사용합니다. 이용자의 메모 등 기록을 판매·양도하지 않습니다. 외부 AI 처리 서비스로의 전송 항목과 목적은 제4조에 설명합니다.

4. 개인정보 처리의 위탁 및 국외 이전

서비스는 데이터 보관과 이미지 저장을 위해 Amazon Web Services(AWS)에 개인정보 처리를 위탁하고 있습니다. 이 데이터는 대한민국 내 리전(서울)에 저장됩니다.

또한 책 추천 기능을 위해 아래와 같이 개인정보가 국외로 이전됩니다.

  • 기록 변경 후 취향 분석
    • 이전받는 자: Voyage AI Innovations, Inc. (미국, legal@voyageai.com)
    • 이전 항목: 이용자가 작성한 한줄평과 삭제하지 않은 텍스트 메모의 합본
    • 이전 목적: 책 추천에 쓰이는 취향 벡터 생성
    • 이전 시점: 한줄평·메모 변경이나 가져오기 후 서버의 비동기 재색인 작업이 실행될 때 자동 전송됩니다. 삭제 후에는 남아 있는 텍스트를 다시 처리할 수 있으며, 분석할 텍스트가 없으면 임베딩을 제거합니다. 추천 화면을 열지 않아도 이 처리는 실행될 수 있습니다.
    • 이전 방법: HTTPS 전송
    • 보유·이용 기간과 학습 이용: 조직의 데이터 저장·모델 학습 이용을 거부하는 opt-out을 사용합니다. Voyage의 공식 안내는 이 설정을 적용한 Voyage 호스팅 API 데이터의 보관 기간을 0일로 설명합니다. 서비스 서버가 보관하는 독서 기록·취향 벡터의 삭제는 제6조를 따릅니다.

현재 운영에서 Google Gemini API를 이용한 추천 이유 생성과 이미지 글자 인식(OCR)은 비활성화돼 있습니다. 추천 이유는 외부 생성 API 호출 없이 기본 안내 문구로 제공합니다. 사진 자체를 위 AI 처리에 보내는 경로는 현재 사용하지 않습니다. 이용자가 AI 전송만 끄는 앱 설정은 아직 없습니다. 전송 시점 변경이나 거부 설정 추가는 별도 제품 결정 사항입니다.

제공자 정책: Voyage 데이터 보호 FAQ. 국외 이전 관련 문의: solux3501@gmail.com.

5. 전송 구간 보호

앱과 서버 간 모든 통신은 HTTPS(TLS)로 암호화되어 전송됩니다.

이용자는 언제든 기록을 삭제할 수 있습니다. 계정 탈퇴 시 데이터는 30일의 유예기간 동안 보관되며, 이 기간이 지나면 독서 기록·메모·업로드 이미지를 포함한 모든 개인정보가 영구 삭제됩니다.

서비스는 현재 유료 결제 기능을 제공하지 않으므로 전자상거래법 등 관계 법령이 보존을 요구하는 거래 기록이 발생하지 않습니다. 향후 결제 기능을 도입하는 경우 보존 항목과 기간을 본 방침에 명시하고 제8조에 따라 사전 공지합니다.
